Portfólio Pessoal Responsivo
Desenvolvemos um site responsivo em HTML e CSS, com layout moderno usando Bootstrap. Inclui seções de perfil, habilidades, trabalhos realizados e formulário de contato. O design garante acessibilidade e ótima experiência em qualquer dispositivo.
Landing Page Startup Tech
Criamos uma landing page fictícia para uma startup de tecnologia. A página apresenta os serviços oferecidos, depoimentos em carousel e formulário de contato. Foram aplicados efeitos de transição e animações em botões e links para transmitir modernidade e inovação.
Jogo da Velha Interativo
Desenvolvemos uma aplicação web do clássico jogo da velha. O sistema permite partidas entre dois jogadores, detecta automaticamente vitórias e empates, e oferece opção de reiniciar o jogo. Demonstra lógica de programação aplicada em JavaScript com interface amigável.
Sistema de Cadastro de Usuários
Criamos um sistema fictício de cadastro de usuários em Java. A aplicação permite inserir dados como nome, e-mail e senha, armazenando-os em memória. O projeto simula processos de back-end, com foco em organização de código e boas práticas de programação orientada a objetos.
